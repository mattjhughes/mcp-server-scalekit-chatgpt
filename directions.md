This repo contains a MCP server written in TypeScript that includes OAuth authentication. The code currently combines the OAuth authentication phase with the MCP server interactions (post-authentication). I want you to separate these out into two separate applications. The first application should complete the OAuth authentication. It should then proxy the MCP client dialogue and forward it to the second application which should implement the MCP server tools. Eventually I need to be able to switch out the MCP server application with only minimal reconfiguration required of the front-end auth application. Use the src-auth folder to contain the authentication app and the src-server folder to contain the MCP server app.
